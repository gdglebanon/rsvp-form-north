# **App Name**: DevFest Registeration 

## Core Features:

- Anonymous User Authentication: Allow users to register without providing personal information.
- One-Page Registration Form: Implement a simple and efficient registration form on a single page.
- Data Storage: Store registration data using Firestore database for persistence.

## Style Guidelines:

- Primary color: A soft blue (#A0C4FF) to evoke trust and simplicity.
- Background color: A light, desaturated blue (#EBF3FF), almost white, creating a clean backdrop.
- Accent color: A complementary soft orange (#FFB3A7) to highlight key interactive elements, providing a warm contrast.
- Font: 'Inter', sans-serif, for a modern, readable, and neutral user interface.
- Clean, single-column layout optimized for easy form completion.
- Simple, minimalist icons to guide users through the registration process.
- Subtle animations for form interactions, such as validation feedback, to enhance user experience.
